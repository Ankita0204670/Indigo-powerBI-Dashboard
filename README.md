# IndiGo Flight Operations & Fare Analytics Dashboard

## Overview

Interactive Power BI dashboard for analyzing IndiGo Airlines flight data, revenue, bookings, routes, and pricing.

## Features

* KPI cards
* Revenue & booking analysis
* Top 10 routes by revenue
* Source and destination city analysis
* Flight duration & stops analysis
* Interactive map and filters

## Tools

* Power BI Desktop
* DAX
* Power Query
* Excel / CSV
